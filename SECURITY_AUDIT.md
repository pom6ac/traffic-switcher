# Аудит безопасности: Traffic Switcher

Основа: Proxy Switcher and Manager (rNeomy/proxy-switcher, MPL-2.0), версия 0.6.7.
Первичный аудит: 17.07.2026. Исправления: 15.11.2026, версия 0.7.0.

## Принятое решение

Расширение сокращено до двух сценариев, которые реально используются: **Direct** и **PAC Script**
(inline-скрипт или PAC по HTTPS-URL). Код неиспользуемых режимов удалён, а не скрыт:
удалённый код нельзя вызвать ни через импорт настроек, ни через политику, ни через ошибку в UI.

## Независимая проверка (раунд 2, 15.11.2026)

Ревью кода отдельным агентом с чистым контекстом (без доступа к этому файлу и выводам первого раунда).
Уязвимостей уровня High, путей внедрения скриптов/HTML и обходов валидации не найдено.
Найдены fail-open-сценарии и неочевидное применение прокси; все подтверждены по коду и исправлены.

## Дополнительное усиление

- Явная CSP в manifest: `script-src 'self'; object-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`.
- Service worker принимает сообщения только со страниц самого расширения.
- При обновлении из хранилища удаляются ключи удалённых функций (`profile.*`, `profiles`, `import-*`, `counter` и др.)
  и значения, не прошедшие валидацию.
- Экспорт выгружает только whitelisted ключи; `*-preferences.json` в `.gitignore`
  (экспорт содержит ваш PAC-скрипт — не коммитить).
- «Startup Proxy» ограничен значениями `no` / `direct`.

## Остаточные риски

- **PAC-скрипт — исполняемый код**, который решает, куда идёт весь трафик. Импортируйте только свои файлы.
- Inline-скрипт применяется автоматически после паузы в наборе. Синтаксически корректный, но
  логически недописанный скрипт (например, неполное имя хоста прокси) всё ещё может примениться.
- Кнопка перезагрузки PAC на доли секунды блокирует запросы (fail-closed, не `direct`).
- `isHttpsUrl` допускает localhost, IP-адреса и IDN-домены — осознанно, адрес PAC вводит сам пользователь.
- PAC-скрипт и URL (могут содержать внутренние имена хостов) хранятся в `storage.local` и экспорте без шифрования.
- Права `proxy` достаточно, чтобы перенаправить весь трафик: устанавливайте расширение только из своего репозитория.
